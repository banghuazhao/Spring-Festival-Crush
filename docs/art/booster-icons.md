# Festival booster icons

Generated as two separate assets with built-in ImageGen. “Shuttle” was interpreted as the existing Shuffle action. Both icons share jade, cinnabar and antique-gold materials with the festival UI. Each delivered asset is a full-color 256 × 256 transparent PNG, losslessly optimized after resizing. Full-resolution originals remain in the Codex generated-images directory.

## Shuffle

Saved asset: `SpringFestivalCrush/Assets.xcassets/ShuffleBoosterIcon.imageset/ShuffleBoosterIcon.png`.
Used in the in-game Shuffle button.
